# KU94 RUN

## 연도별 챌린지 설정과 기록 보호

`fetch_data.py`는 활성 연도의 설정만 사용하고 `data/<연도>.json`에 해당 연도 기록만 저장합니다. 기존 2026 Actions Variables(`START_DATE=2026`, `CURRENT_SHEET_URL`)는 계속 동작합니다. 다음 챌린지를 시작할 때는 GitHub 저장소 **Settings → Secrets and variables → Actions → Variables**에 아래 값을 등록합니다.

- `ACTIVE_CHALLENGE_YEAR`: 예를 들어 `2027`
- `CHALLENGE_CONFIGS_JSON`: 연도별 `start_date`, `sheet_url`, `rules` 설정 JSON. 활성 연도 항목이 없으면 실행이 중단되어 2026 시트로 잘못 기록하지 않습니다.

예시 구조:

```json
{
  "2026": {
    "start_date": "2026-07-08",
    "sheet_url": "기존 2026 시트 URL",
    "rules": "2026년 규칙"
  },
  "2027": {
    "start_date": "2027-실제-시작일",
    "sheet_url": "https://docs.google.com/spreadsheets/d/12o3Hj9diPJoUddmoCF1o4JYeuOAOSyacF8DQRnl2rEU/edit",
    "rules": "2027년 확정 규칙"
  }
}
```

JSON 전체를 `CHALLENGE_CONFIGS_JSON` Actions Variable 값으로 저장하고, 각 시작일과 규칙을 실제 값으로 채웁니다. 향후 2026 기록을 다시 처리할 일이 있으면 2026 항목도 함께 유지합니다.

완료 연도는 `data/meta.json`의 `completed_years`에 기록됩니다. 완료 연도 파일이 없거나 비어 있거나 JSON이 잘못되었으면 자동 작업이 중단됩니다. 기존 아카이브와 새 데이터가 다를 때도 자동 덮어쓰기를 거부합니다. 우선 Git 커밋 기록에서 `data/2026.json`을 복구하세요. 의도적인 정정에만 `ALLOW_COMPLETED_YEAR_REWRITE=2026`처럼 정정할 연도와 같은 값을 설정해 한 번 실행하고, 실행 후 해당 변수를 삭제하거나 비활성화하세요.

챌린지 종료 시 생성된 `data/<연도>.json`과 `data/meta.json`을 검토한 뒤 커밋·푸시하면 저장소의 Git 이력에 종료 시점 아카이브가 남습니다. 파일을 실수로 삭제하거나 비우면 GitHub의 해당 파일 History에서 마지막 정상 버전을 복원하고 커밋하세요. 원본 스프레드시트도 보존하면 추가 복구 수단이 됩니다.


## 원본 스프레드시트 축하 기능 (GAS)

`gas/ku94_celebrations.gs`를 원본 챌린지 스프레드시트의 **확장 프로그램 → Apps Script** 프로젝트에 붙여 넣고 저장합니다. 함수 목록에서 `installKu94Celebrations`를 한 번 실행해 권한을 승인하면 편집 트리거와 요약 탭이 만들어집니다.

- 10·30·50·100회 배지는 `챌린지 요약` 탭에 표시됩니다. 달성한 배지는 누적 표시합니다.
- 100회 완주자의 원본 행은 조건부 서식으로 강조하고, 별도 요약에 이름을 모읍니다. 원본 표에 열을 삽입하지 않습니다.
- 달리기 횟수가 단계별 기준을 새로 넘으면 편집 화면에 축하 알림이 표시됩니다. 현재 기록을 기준값으로 저장하므로 설치 전에 달성한 단계에 대한 알림은 소급하지 않습니다.
- 바로 전날 셀에 `휴식`, `rest`, `x`, `×`가 명시되어 있고 다음 날 달리기를 입력하면 복귀 알림을 표시합니다. 빈 셀은 미입력일 수 있어 휴식으로 추정하지 않습니다.
- `챌린지 요약 갱신` 메뉴로 요약을 수동 갱신할 수 있습니다. 요약 탭을 제외한 원본 기록 값은 변경하지 않습니다.

시트의 헤더에 `이름`, `달리기 횟수`, 요일 열이 있어야 자동으로 표를 찾습니다. 이 기능은 사람이 시트에 직접 입력할 때 동작합니다. 알림은 스프레드시트 편집 화면에서만 보이며, 시트를 닫은 사용자에게 별도 메시지를 보내지는 않습니다.
